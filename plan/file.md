
## 1. 设计目标与核心原则

1. \*\*零水平溢出与防换行\*\*：消除重复的 `路径` 列，将目录信息内聚至左侧目录轨与文件名副行；对 `大小`、`修改时间`、`操作` 列实施严格固定宽度与 `whitespace-nowrap`，确保在 `≥1280px` 屏幕上完整展示所有列。

2. \*\*保留并统一终末地视觉资产\*\*：延续原版极具辨识度的 \*\*`文件 FILES ■ ///////`\*\* 斜线装饰标题头与 45° 切角胶囊按钮，将高亮色统一对齐至全站主色 \*\*工程黄 `#FFDE00`\*\*。

3. \*\*通道能力自适应（RW / RO）\*\*：不写死静态限制文案，根据当前数据通道（如 `云端` 只读或 `LAN_FTPS` 可读写）动态点亮或锁定 `删除` 操作，给出明确权限态徽章。

4. \*\*安全销毁与非阻塞传输\*\*：针对打印机存储特性，下载提供底部非阻塞进度队列条，删除采用带黑黄警示斜纹的二次确认模态框与串行队列反馈。

## 4. 模块级详细规格

### 4.1 终末地标题头与存储权限条

\* \*\*标题头（48px）\*\*：左侧大号粗体 `文件` + 右下角标 `FILES` + 实心方块 `■` + 铺满剩余宽度的斜线纹理条 `.endfield-hatch-bar`。

\* \*\*权限与容量条（36px）\*\*：

  \* \*\*左侧上下文\*\*：`m3凯尔希 // 通道标识`（如 `LAN_FTPS` 或 `CLOUD`）。

  \* \*\*中间容量条\*\*：显示当前存储介质的总容量与已用比例（如 `内部存储: 1.42 / 8.00 GB · 15 个文件`）；若设备接口暂未上报总容量，仅展示 `已统计体积: 42.8 MB · 15 个文件`。

  \* \*\*右侧权限状态徽章\*\*：

    \* \*\*可写态\*\*：绿框微标 \*\*`[RW // 可下载 · 可删除]`\*\*。

    \* \*\*只读态\*\*（如当前 `云端` 通道不支持删除）：灰框虚线标 \*\*`[RO // 云端只读 · 不可删除]`\*\*，删除按钮自动置灰并附带悬停说明，不再使用整段长文案占空间。

### 4.2 单行集成控制工具栏（46px）

将原先竖排三行的操作收拢到单行内，按“范围 → 筛选 → 动作”从左到右排列：

1. \*\*介质切换组\*\*：`[内部存储]` `[外部存储]`（切角胶囊，激活态 `#FFDE00` 黑字黄底）。

2. \*\*文件类型组\*\*：`[全部]` `[模型]` `[延时摄影]` `[视频]`。

3. \*\*即时检索框\*\*：`// 过滤文件名...`（前端即时检索，输入毫秒级过滤，无需等待请求）。

4. \*\*排序器\*\*：下拉菜单支持 `修改时间 (新→旧)`、`修改时间 (旧→新)`、`文件大小 (大→小)`、`名称 (A→Z)`。

5. \*\*条件批量操作组\*\*（仅当列表勾选 `≥1` 项时动态出现）：

   \* \*\*`[批量下载 (N)]`\*\*：黄框高亮按钮。

   \* \*\*`[批量删除 (N)]`\*\*：红框警示按钮（只读通道下禁用）。

6. \*\*手动刷新\*\*：最右侧 \*\*`[↻ 重新读取]`\*\*，加载中显示扫描动效与 `LOADING...`。

### 4.3 左侧目录过滤器（Directory Rail · `180px`）

\* \*\*自动目录提取\*\*：遍历后端返回的所有文件 `dir` 字段（如 `/userdata/model/history`、`/userdata/model/bbl`），提取末级或相对路径生成目录列表并统计文件数。

\* \*\*交互\*\*：

  \* 点击 `全部目录 (15)` 展示当前介质与类型下的所有文件；

  \* 点击 `history (11)` 瞬间过滤出该目录文件。

  \* 若当前视图仅含 1 个目录（例如只有根目录），支持自动折叠或保持极简展示。

### 4.4 中央文件矩阵表格（核心防裁切规范）

采用 Flexbox / CSS Grid 严格控制列宽，行高设定为 \*\*`54px`\*\*（容纳主文件名 + 目录副行，视觉宽松不拥挤）：

| 列名 | 宽度与溢出规则 | 内容排版规范 |

| :--- | :--- | :--- |

| \*\*勾选列\*\* | `flex: 0 0 42px` | 复选框，支持表头全选当前筛选结果与 `Shift` 区间连选 |

| \*\*文件名称 (`NAME`)\*\* | `flex: 1 1 260px; min-width: 0;` | \*\*第一行\*\*：类型徽标（如 `[3MF]`）+ 文件名（强制 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`）。&lt;br&gt;\*\*第二行\*\*：`11px` 暗灰等宽字展示所在目录路径（如 `// /userdata/model/history`）。 |

| \*\*大小 (`SIZE`)\*\* | `flex: 0 0 100px; white-space: nowrap;` | 右对齐等宽字体（`tabular-nums`），如 `4.23 MB`、`945.78 KB`，\*\*禁止任何换行\*\*。 |

| \*\*修改时间 (`MODIFIED`)\*\* | `flex: 0 0 156px; white-space: nowrap;` | 等宽字体（`tabular-nums`），格式 `YYYY-MM-DD HH:mm`（如 `2026-11-26 16:05`）。 |

| \*\*操作 (`ACTIONS`)\*\* | `flex: 0 0 148px; white-space: nowrap;` | 并排两个切角微按钮：\*\*`[↓ 下载]`\*\*（悬停亮工程黄）+ \*\*`[删除]`\*\*（悬停亮警示红；点击触发阻止冒泡，不触发行选中）。 |

\* \*\*空态与加载态\*\*：

  \* 加载中：表格区域展示终末地风格扫描骨架屏（`SCANNING STORAGE DIRECTORY...`）。

  \* 空目录：居中准星框提示 `NO_FILES_FOUND // 当前存储或筛选条件下无文件`。

### 4.5 右侧文件检视器（File Inspector · `300px`）

点击表格任意行激活右侧检视面板（默认隐藏或固定展示，带右上角 `[×]` 关闭按钮）：

1. \*\*文件头部与完整名称\*\*：完整展示超长文件名（允许正常换行），彻底解决列表里被省略号截断后看不全的问题。

2. \*\*可视化预览区\*\*：

   \* 若 Bridge 已解析 `.3mf` 内置缩略图，则展示模型盘面预览图；未解析时展示带文件格式字样的工业线框占位图。

   \* 若为 `.3mf` 文件且具备元数据，展示切片摘要：`预计耗时`、`耗材总重`、以及适配多头机型的\*\*喷嘴/工具头使用数量\*\*（例如 `H3C: 3 工具头`）。

3. \*\*完整路径与复制\*\*：显示完整 POSIX 路径（如 `/userdata/model/history/TATA_v1.11_plate_2.gcode.3mf`）+ `[复制路径]`。

4. \*\*Bridge API 透视区\*\*：面向第三方开发者，直接给出操作该文件的接口端点与参数，点击可复制 `curl`：

   \* `GET /api/v1/files/download?storage=internal&path=...`

   \* `DELETE /api/v1/files?storage=internal&path=...`

5. \*\*主操作区\*\*：通栏按钮 \*\*`[ ↓ 下载到本地 ]`\*\* 与 \*\*`[ 🗑 从打印机删除 ]`\*\*。

## 5. 核心操作流与状态机规范

### 5.1 文件下载流（单文件 & 批量下载）

\* \*\*单文件下载\*\*：点击 `[↓ 下载]` 后，由 Bridge 代理拉取打印机 FTPS/本地文件流并推送至浏览器；同时底部弹出 `38px` 高的 \*\*`[TRANSFER_QUEUE]`\*\* 传输条，实时更新进度条、已接收字节数与当前速率（如 `4.1 / 6.41 MB · 1.2 MB/s`）。

\* \*\*批量下载\*\*：勾选多个文件点击 `[批量下载 (N)]` 时，Bridge 后端打包为 `.zip` 流式输出，或前端按顺序逐个加入下载队列执行，传输条显示总任务进度（`正在传输 2/4`）。

\* \*\*异常处理\*\*：若 FTPS 连接中断或打印机忙碌导致传输失败，传输条变为红色并保留 `[重试]` 按钮。

### 5.2 安全删除流（警戒确认 + 串行执行）

删除打印机内部文件属于不可逆高危操作，必须经过严谨交互闭环：

1. \*\*警戒确认弹窗（Hazard Modal）\*\*：

   \* 弹窗顶部嵌有 `10px` \*\*黑红斜向警戒条纹\*\*，标题 `/// CONFIRM_PURGE // 确认删除存储文件`。

   \* 展示待删除清单（超过 5 个时可滚动，显示文件名、存储介质与可释放总空间，如 `共 2 个文件 · 释放 5.36 MB`）。

   \* 操作按钮：`[取消]` / \*\*`[确认永久删除]`\*\*（警示红实底）。

2. \*\*串行删除队列（针对批量删除）\*\*：

   \* 考虑到打印机 FTPS/控制接口对并发删文件的稳定性限制，点击确认后前端/Bridge 按\*\*串行顺序\*\*逐个删除。

   \* 弹窗内切换为进度反馈：`正在清理 (2/5): tmpaiwpli51_Lumina...`，支持显示单条成功/失败状态，全部完成后自动关闭弹窗并触发一次 `重新读取` 同步最新列表。
