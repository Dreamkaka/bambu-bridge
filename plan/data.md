## 1. 页面核心定位与重构逻辑

1. \*\*职责彻底解耦\*\*：实时监控画面与常规控制已由 Page 1（概览页）承担，Page 2 \*\*完全移除摄像头画面与冗余大卡片\*\*，释放 100% 的视觉空间给“字段检索”与“波形分析”。

2. \*\*一屏 20+ 行数据可见\*\*：将顶部信息压缩为 `40px` 上下文条，把原本 10 排近 90 个扁平标签收拢为“单行语义过滤 + 左侧命名空间树”，确保中间数据表成为绝对主角。

3. \*\*全高多通道示波器\*\*：右侧取消图传占位后，整列独占用于 \*\*Signal Scope（多通道时序示波器）\*\*，支持\*\*分轨/叠加\*\*两种波形视图，既能替代原本的温度折线图，又能让表格中任意数值/布尔字段点击 `[+ 走势]` 直接注入同轴对比。

## 4. 各模块详细规格

### 4.1 顶部上下文状态条（Top Context Strip · `40px`）

精简展示当前观察的设备上下文，无多余按钮干扰：

\* \*\*左侧\*\*：`[< 返回概览]` 导航按钮 + 设备与采集通道标识（如 `m3凯尔希 // 云端` 或 `UNIT_01: H3C // LAN_MQTT`）。

\* \*\*中间\*\*：一行浓缩核心读数胶囊：`任务: 已完成 (100%)` · `NOZ: 26°C` · `BED: 26°C` · `同步: 03:31:31`。

\* \*\*右侧\*\*：

  \* \*\*`[RAW_JSON]`\*\*：点击从右侧滑出抽屉，展示当前拉取的未经拍平的原始嵌套 JSON 树，支持关键词查找与整包复制。

  \* \*\*`[导出快照]`\*\*：将当前全量 957 项读数导出为带时间戳的 `.json` 或 `.csv` 文件。

### 4.2 检索与单行语义过滤栏（Search & Filter Bar）

彻底取代原先的 10 行标签墙，控制高度在 `80px` 以内：

1. \*\*终端风格搜索框\*\*：

   \* 提示文案：`// 搜索名称、路径或读数 (支持空格分词、/正则/)`，支持 `CTRL + K`（Mac 为 `CMD + K`）快速聚焦，`ESC` 清空。

   \* 匹配逻辑：同时检索 `path`（路径）、`label`（中文含义）与 `value`（当前读数），命中部分高亮标黄。

2. \*\*单行高频语义胶囊（固定最多 8\~9 枚，禁止按单字段生成胶囊）\*\*：

   \* \*\*功能视图类（排在最前，用竖线分隔）\*\*：

     \* `[全部 957]`：默认态，选中为黑字工程黄底。

     \* \*\*`[⚡ 近期跳变 N]`\*\*：只显示最近 `30 秒` 内数值发生过变化的数据行，并按“最后变动时间”倒序排列（操作机器时抓未知协议字段的核心利器）。

     \* \*\*`[? 未收录 N]`\*\*：只过滤出词典尚未覆盖的字段（如 `[2D.bs.bi](http://2D.bs.bi)[0].clock_in`），方便集中完善翻译字典。

   \* \*\*领域归类（收编所有零散 1 项 Key）\*\*：

     \* `[设备与运动 246]`（收编 `device`、`fun`、`aux`、`mc_*`、`hw_switch_state` 等）

     \* `[AMS 供料 221]`（收编 `ams`、`AMS 状态`、`AMS RFID`、`已读槽位` 等）

     \* `[双头/外挂料盘 234]`（收编 `vir_slot` / `vt_tray` 等虚拟槽位数据）

     \* `[2D / 3D 工艺 37]`（收编 `2D`、`3D`、`RefillInfo`）

     \* `[任务与队列]`（收编 `job`、`plate_*`、`queue*`、`progress`、`remain_time`）

     \* `[系统/网络/相机状态]`（收编 `net`、`online`、`upgrade_state`、`xcam`、`ipcam` 文本状态）

### 4.3 左侧：命名空间目录树（Namespace Tree · `220px`）

\* \*\*自动解析生成\*\*：根据字段路径中的 `.` 与 `[index]` 自动构建树状层级（例如 `ams` → `ams[0]` → `tray[0]`\~`tray[3]`）。

\* \*\*子树去噪\*\*：对于 `ams (221)`、`双头外挂料盘 (234)` 这类数组展开体积庞大的子树，在目录树上直接定位到单个 `[0]`、`[1]` 槽位即可瞬间过滤掉 75% 以上的重复行。

\* \*\*状态角标\*\*：每个树节点右侧显示该子树包含的字段数；若子树内有字段正在跳变，点亮微小的黄色闪电标 `⚡`；若支持折叠，左栏可收起成一条 `32px` 的细边条。

### 4.4 中央：全量遥测矩阵表格（Telemetry Matrix）

\* \*\*性能要求\*\*：面对近千条（且 H3C 多工具头 + 多 AMS 扩展后可能达 1200+ 条）高频刷新的字段，必须使用\*\*虚拟列表（Virtual Scrolling）\*\*渲染，保障滚动与每秒刷新时 CPU 占用极低。

\* \*\*5 列结构规范\*\*：

  1. \*\*路径 (`PATH`, 占 \~36%)\*\*：父路径 `#6B7280` + 叶子键名 `#F4F4F5`。行悬停时右侧浮现极简图标 `[复制路径]`。

  2. \*\*含义 (`LABEL`, 占 \~20%)\*\*：显示中文业务名称；未收录字段显示虚线胶囊 `[未收录]`。

  3. \*\*读数 (`VALUE`, 占 \~22%)\*\*：按数据类型着色，右对齐或左对齐保持等宽。\*\*触发跳变时，该行背景闪动 `800ms` 工程黄微光\*\*。

  4. \*\*变更 (`DELTA`, 占 \~10%)\*\*：展示上一次变动量与距今时间（如 `+1°C · 4s`、`否→是 · 18s`），无变动显示 `—`。

  5. \*\*操作 (`SCOPE`, 占 \~12%)\*\*：

     \* 数值型（`number`）与布尔型（`boolean`，在示波器中以 `0/1` 阶梯波形绘制）展示 \*\*`[+ 走势]`\*\* 按钮；点击后固定入右侧示波器，按钮切换为实底工程黄 \*\*`[● 监视中]`\*\*。

     \* 纯字符串/哈希值（如 `task_id`、`md5`）禁用走势按钮（置灰无干扰），保留 `[复制值]` 按钮。

### 4.5 右侧：全高多通道时序示波器（Signal Scope · `360px`）

彻底移除摄像头后，右侧获得完整的垂直空间，成为本页的第二大核心生产力工具：

1. \*\*顶部工具栏\*\*：

   \* 标题：`SIGNAL_SCOPE // 仅保留本页周期`

   \* \*\*视图模式切换\*\*：\*\*`[分轨]`\*\* vs \*\*`[叠加]`\*\*

     \* \*\*分轨模式（默认推荐）\*\*：每个被钉选的信号独占一条微型水平泳道（高度自均分，最多支持 6 轨）。\*\*优势\*\*：你可以同时把 `喷嘴温度 (220°C)`、`部件风扇 (80%)`、`[2D.bs.bi](http://2D.bs.bi)[0].est_time (0)` 和布尔信号 `炒面检测 (0/1)` 放在一起上下对齐时间轴观察，彻底解决不同量纲无法同图对比的问题！

     \* \*\*叠加模式\*\*：共享同一 Y 轴或左右双 Y 轴，适合专门对比 `喷嘴 vs 热床` 或 H3C `T01` vs `T03` 温度同步曲线。

   \* 采集控制：`[● LIVE]`（点击可暂停波形冻结观察细节，暂停时背景微标 `HOLD`）、`[清空]`、`[导出 CSV]`。

2. \*\*已钉选通道列表（最多同时支持 6 个通道）\*\*：

   \* 默认预置：页面打开时自动尝试钉选 `喷嘴温度` 与 `热床温度`（无缝保留原先一进来就能看温控曲线的习惯）。

   \* 每个通道卡片包含：通道色块（依次分配 `#FFDE00`、`#38BDF8`、`#22C55E`、`#F59E0B`、`#C084FC`、`#FB7185`）、中文名/末级路径、\*\*实时值\*\*、以及小字统计 \*\*`MIN` / `MAX` / `AVG`\*\*，右侧带 `[×]` 移除按钮。

3. \*\*交互式波形画布\*\*：

   \* 采用 `Canvas` 或轻量 `SVG` 渲染（避免重型图表库在每秒刷新时卡顿）。

   \* 鼠标在任意时间点悬停，所有泳道同步出现一条 \*\*1px 白色垂直时间准星线\*\*，浮动面板显示该精确时刻（如 `03:31:18`）所有通道的数值快照。

   \* \*\*离线/断流处理\*\*：如果设备通道切换或拉取超时，示波器自动暂停推进并在最新位置打上红色虚线断层标 `SIGNAL_LOST`，不绘制虚假直线。

4. \*\*底部环形缓冲状态\*\*：

   \* 显示当前页内存采样进度：`RING_BUFFER: 184 / 300 帧 (约 5 分钟)`（超过上限自动滚动淘汰最旧帧，防止长挂网页内存泄漏）。
